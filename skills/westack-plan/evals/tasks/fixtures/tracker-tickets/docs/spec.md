# Saved searches

Signed-in users run the same searches every day. Let them keep them.

## Requirements

- R1: a signed-in user can save the current search under a name.
- R2: they can list their saved searches and delete one.
- R3: once a day, an email lists the new results of each saved search that has alerts turned on (needs R1).

## Not in scope

Sharing saved searches with other users.
