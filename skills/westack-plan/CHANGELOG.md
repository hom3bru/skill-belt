## 1.0.0-alpha.5 (P2 adoption), unreleased

Ideas only, in westack's own words. One helper change (SS-45), written red first with a broken copy of the script's own source.

- P2 (SS-45): `scripts/plangraph.py`. The first backticked command of an automated criterion is read as text for a gate that cannot fail. `fixed-output` is an error (exit 1): the command prints fixed text or masks its own failure (`echo ok`, `printf`, `true`, `exit 0`, an inline program that only prints a literal, or a trailing `; echo ok`, `|| true` or `| true`). `weak-expectation` (`grep -q ok`) and `path-as-regex` (a path searched as a pattern) are warnings. A lone word such as `printf` is prose and is not read. The lint is a heuristic pre-check and never replaces a broken-copy run (the script's header says so); `references/living.md` and `SKILL.md` name the check. The `westack-verify` sentence is g4b's.
- P2 (HD-16): `references/slices.md`. When workers take slices, the coordinator sizes each to one worker's budget and splits one that will not fit before dispatch; workers never pick their own slice or edit the plan. The orchestrate `dispatch.md` part is deferred (not built).
- P2 (HD-19): `references/living.md` "Keeping it current". A done slice stays done; a failed later check adds a new slice that cites it (`Retry of: S3`), keeps the old one as history, and goes to a fresh context that re-derives its own checks. The record-level chain rule is g6's (`retry_of`).
- P2 (HD-37): `references/living.md` Resume. Compare the plan's SHA-256 with the one the last pause or hand-off recorded; a plan that changed since is refused until the Decision log holds an amendment with old and new hashes and the slices it changes, and finished slices it touches are untrusted until their cheapest check is re-run. Adapted: a living plan changes at every stopping point, so the seal is the hash at the last pause, not the hash at the start. The optional `plan {path, sha256}` field is a contract change (g6).
- P2 (SS-69): `references/living.md` "Keeping it current". A convergence pass compares the code with the requirements and slices and appends what is left as new slices that cite the requirement and a gap type (missing, partial, contradicts or unrequested), never renumbering; a pass that finds nothing writes nothing.
- P2 (WA-14): `references/slices.md` Rollback. The rollback is written before the slice's first effect, safe if that effect never ran (test that case); undo runs in reverse, each step ran, undone or only stopped, and a failed undo is partly undone. The core `build.md` half is in the core changelog.
- P2 (WA-51): `references/slices.md` Rollback. A rollback target is the last verified revision, whose receipts stand; any other target is a new candidate. Running a rollback (read back that the target is healthy, else failed, never reverted) belongs to westack-deploy (pending).
- P2 (WA-73): `SKILL.md` section 3. For a large or architectural change, offer (never impose) a blind second plan from a fresh-context planner given only the request, list where the plans disagree as decisions with a recommendation, and build only after the user chooses. The `critique.md` pointer is g3's.
- P2 (WA-78): `references/living.md` Hand-off. A delegate's report echoes the plan's path and SHA-256, and one built on another hash is stale; running delegates are told when the plan changes and the redo list is given. The `delegation.md` brief line is g2's.
- Tests: `tests/test_plangraph.py` `GateLintTests` (red first against the old script; the broken copy removes the lint and exits 0 on the echo). The wording pins for the text rules are in `tools/tests/test_p2_build.py`.
- Donor records (P2): `provenance/donors.json` gains 12 `p2:` records for the 9 applied items above: pinned blob URLs, lowercase SHA-256 and byte counts, a licence note, "ideas only" and the item ids each supports. Restricted sources (proprietary, unlicensed, source-available, GPL, and the X-post mirrors) are marked never to quote. The file's `reviewed` date is 2026-10-29 and its policy says how the `p2:` records were read.
