# ENG-142: Rate-limit login attempts

Limit POST /login to 5 attempts per minute per client IP.

When the limit is exceeded, respond with status 429 and this JSON body:

    {"error": "too_many_attempts", "retry_after": <seconds until the window resets>}

Also send a Retry-After header with the same number of seconds.

Acceptance:
- The sixth attempt inside one minute from the same IP gets the 429 body above.
- Attempts from other IPs are not affected.
- A successful login does not reset the count.
