## 1.0.0-alpha.4 (P1 adoption), unreleased

- **SS-12.** `scripts/diffaudit.py` flags `check-config-changed` (needs a decision) for an edit to a linter, formatter or type-check configuration or an ignore file that gives no reason in the diff. A first-time creation is fine, a change that only removes ignore-file lines tightens the gate and is not flagged, and a reason is a comment of three words or more on an added line, or an inline comment on one. Files shared with other settings (`pyproject.toml`, `setup.cfg`, `tox.ini`, `package.json`, `tsconfig*.json`) count only when the change touches a check setting.
