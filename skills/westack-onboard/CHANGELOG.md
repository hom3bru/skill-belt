# Changelog

## 1.0.0-alpha.3 (opt-in extensions), unreleased

Four opt-in extensions, each off by default (`references/extensions.md`): `--embed URL` adds a vector arm through a local embedding endpoint (vectors stored in the index, a third arm in the rank fusion; another host needs `--allow-remote-embed`); `--tree-sitter` uses installed grammars for JavaScript, TypeScript, Go and Rust, so class and impl methods become symbols and calls keep their kind, and switching it re-walks; `scripts/indexsync.py` exports an index as JSONL after a secret scan that refuses the whole export on one finding, and imports an export for the same repository with local pages winning conflicts (git moves the folder under the user's grant; the script runs none); `scripts/mcpserver.py` serves the read verbs over MCP stdio and obeys the trust tier. Schema 4 (a vectors table). With every extension off, the S15 and S16 test files run unchanged (byte-identical to alpha.2). Tests: 80 (16 new), with broken copies for the host check, the vector fusion, an unguarded tree-sitter import, a flag-blind chunker, a skipped secret check and a tier-blind server.

## 1.0.0-alpha.2 (index governance), unreleased

Trust tiers per repository in the user's policy file (`references/governance.md`): deny refuses build, update, search and the graph; read-only refuses build, update and the guidance ping; read-write and unset allow everything. `codeindex.py` enforces them (exit 77) and `doctor` reports them; `policy --set` writes them under the user's grant. A corrupt policy file is moved aside and every repository stays read-only until it is restored or replaced. `guidance` keeps a search-guidance block in AGENTS.md or CLAUDE.md true: a throwaway page indexed, found within three tries and deleted, then the block written between westack markers, or removed when any step fails; a dry run without `--write`. Tests: 64 (17 new), with broken copies that ignore read-only, compare keys case-sensitively, fail open on a corrupt file and write the block regardless.

## 1.0.0-alpha.1 (call graph, context pack and delta), unreleased

`codeindex.py` gains `def`, `refs`, `callers`, `callees`, `context` and `delta`. Definitions and calls are recorded per chunk (Python by `ast`, telling `f(...)` from `obj.m(...)`; other languages by call patterns), so a method call resolves only to methods and a bare call only to functions and classes, with a same-file definition preferred. Callers are labelled "same file", "names the module" or "by name"; `--in <path>` pins one definition and keeps only linked callers. A context pack takes the definition, then callees, then callers inside the token budget and lists what did not fit. Each run and its file changes are logged, so `delta --since <commit>` reports added, modified, renamed and deleted files since a clean run at that commit (re-chunking is not a change). Schema 3 and chunker 3: an older index is reported by `doctor` (no longer a traceback, found in the live run) and migrated and re-walked by `update`. Tests: 47 (20 new), each query with a broken-copy control.

## 1.0.0-alpha.0 (first build: the repository index), unreleased

westack-onboard is built: orient, explain and find modes over this repository's own code, with a local index as the search tool and reading as the proof. `scripts/codeindex.py` (`build`, `update`, `search`, `show`, `doctor`) runs no command: it reads tracked paths from the `.git` index file (versions 2 and 3; a saved `git ls-files` otherwise), HEAD and the remote from `.git`, and keeps a SQLite index in the user's cache, never in the repository. FTS5 when Python has it, a pure-Python BM25 with the same weights when not; chunks by Python `ast`, definition patterns, Markdown headings or word windows; reciprocal-rank fusion of a chunk arm and a title arm with title, recency and backlink boosts; token budgets. Incremental updates by size, time and content hash, renames by content, soft deletes, a watermark held while failures are unacknowledged, a chunker-version re-walk, a lock with stale takeover after five minutes and an atomically written state file. Ideas from gbrain and gstack's gbrain sync at the mirror pins. Tests: 27 on temporary git repositories, with broken-copy controls for each sync rule.
