# Portfolio edition changes

## 3.0.0-grok-draft.r13-portfolio.1

Distribution preparation based on **adopt-adapt 3.0.0-grok-draft.r13**. Earlier lineage: adopt-adapt 2.11.0, adopt-adapt-v2 2.0.0, and the 3.0.0 proposal. License remains **Proprietary (Matt Kolkin)**; this edition grants no new reuse rights.

- Generalized discovery, recipient rules, routing and examples for user-specified repositories and workflows. Private architecture, host inventories, historical project reviews and personal source locations are excluded from this public edition.
- Retained legacy profile filenames/IDs as compatibility stubs. They contain no project policy; use the generic profile until current recipient instructions and receiving seams are inspected.
- Removed the private bundled path-policy snapshot. `classify-path --rules FILE` applies explicit caller-supplied rules. Legacy `radar-path` is an alias requiring the same rules and refuses no-rules use. Classification is not authorization. Existing path normalization, governed exclusions, measurement precedence and conservative-default checks now use synthetic rules, with additional refusal tests.
- Preserved plans-only evaluation, user authority, paid-policy replacement requirements, evidence-before-verdict ordering, every-input accounting, legal/injection gates, history exclusion, self-change boundaries and protected evidence/receipt checks. Unrelated runtime helpers and their assertions are unchanged.
- Updated the edition version and regenerated the exact-byte release manifest. Tests and package validation establish only their stated local scopes; no public trigger accuracy, verdict quality, native host activation or general effectiveness claim follows.

Internal development history is intentionally not redistributed. Baseline version lineage is recorded above; this changelog does not import past verdicts or private research records into new assessments.
