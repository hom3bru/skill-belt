# Target profile: generic repository

## Routing signals
A repository recipient that no installed profile's signals match → `generic` (high when the user names that repository or its root, medium when only the cwd points to it). Never borrow another profile's rules for it.

## Profile
Use when the recipient is a repository with no dedicated profile. Read its AGENTS.md / CLAUDE.md / CONTRIBUTING, entrypoints, tests and dependency manifests first. Use the generic rubric (relevance 0–3, novelty 0–3, fit 0–2, surface 0–2, one penalty). Do not import another profile's agent structure, perimeter or erasure rules. Record missing rules as UNKNOWN, not as permission.
