## Findings and limits (evidence before disposition)

1. **Transformation and oracle must be named separately.** UM's [method/fidelity table](https://github.com/rehan-remade/universal-modder/blob/550651675153070cce68066e07c3c8f95df86d08/knowledge/techniques/engine-recreation-measures-and-fidelity.md#L28-L37) separates byte match, linked build and behavior. N64Recomp [emits MIPS instructions as C and requires runtime support](https://github.com/N64Recomp/N64Recomp/blob/ffb39cdad1da5de07eaaa48bd1db4a89a7986771/README.md#L15-L34). OpenMW describes a replacement engine. AnyPS5 [relinks executable inputs and provides API/system libraries](https://github.com/boykopovar/AnyPS5/blob/4fb937abe9084306aaa0572eb6b7046cf5902522/docs/dev/ARCHITECTURE.md#L32-L46), with a separate [runtime shader translation pipeline](https://github.com/boykopovar/AnyPS5/blob/4fb937abe9084306aaa0572eb6b7046cf5902522/docs/dev/ARCHITECTURE.md#L60-L95). A native output or a project called a port is not evidence of recovered source. Limit: classify components/claims separately when methods overlap; executable relinking/API compatibility can use `other` instead of forcing a misleading category.

2. **Claim-wise pass does not establish whole-program equivalence.** REA's [verifier](https://github.com/morluto/rea/blob/54e2890b300f2935db592edd7d01fc38c3198ffc/src/domain/reconstructionVerification.ts#L68-L111) checks declared claims only; its [authority gate](https://github.com/morluto/rea/blob/54e2890b300f2935db592edd7d01fc38c3198ffc/src/domain/reconstructionVerification.ts#L272-L330) distinguishes structural artifacts from controlled replay, rejects the same observation on both sides, and checks replay environments. Limit: omitted claims still escape a declared-claims verifier. R6 requires declared method scope and keeps structural evidence from certifying behavioral results.

3. **Preserve runtime semantics and incomplete observations.** UM documents [tick/event ordering, float/alias/error semantics and imported-map limits](https://github.com/rehan-remade/universal-modder/blob/550651675153070cce68066e07c3c8f95df86d08/knowledge/techniques/engine-recreation-measures-and-fidelity.md#L39-L63). REA's [readiness contract](https://github.com/morluto/rea/blob/54e2890b300f2935db592edd7d01fc38c3198ffc/docs/reconstruction-readiness.md#L35-L64) requires partial-order/finite-trace semantics for concurrency and preserves incomplete comparisons as unknown. Limit: a replay validates only its observed path; a foreign map running under host-game rules does not reproduce the foreign game. Applied to method checks, not as universal game-specific semantics.

4. **Progress is a census, not a correctness score.** AnyPS5's [progress contract](https://github.com/boykopovar/AnyPS5/blob/4fb937abe9084306aaa0572eb6b7046cf5902522/docs/dev/PROGRESS.md#L5-L19) counts declared functions, distinguishes shared-source wrappers, excludes test callbacks, and preserves snapshot totals. Changing duplicate accounting can change percentages without changing functionality. Limit: the scanner classifies some bodies as implemented without verifying their ABI/behavior. R6 records numerator, denominator, unit, snapshot basis and exclusions, and keeps four result dimensions separate.

5. **Present, stubbed, ignored and implemented are separate states.** AnyPS5's [import audit documentation](https://github.com/boykopovar/AnyPS5/blob/4fb937abe9084306aaa0572eb6b7046cf5902522/docs/user/USAGE.md#L123-L138) and [unimplemented exports](https://github.com/boykopovar/AnyPS5/blob/4fb937abe9084306aaa0572eb6b7046cf5902522/core/libs/prx/libSceAgc/Unimplemented.cpp#L8-L19), plus N64Recomp's [stubbed/ignored configuration](https://github.com/N64Recomp/N64Recomp/blob/ffb39cdad1da5de07eaaa48bd1db4a89a7986771/src/config.h#L38-L66), show why symbol presence is insufficient. Limit: reading a throwing-stub declaration is not observing the unsupported path execute. R6 asks for those paths and fallbacks in scoped acceptance evidence.

6. **Do not trust a green process exit or output pattern by itself.** N64Recomp's [live fixture](https://github.com/N64Recomp/N64Recomp/blob/ffb39cdad1da5de07eaaa48bd1db4a89a7986771/LiveRecomp/live_recompiler_test.cpp#L270-L298) compares bounded output bytes, but its [runner](https://github.com/N64Recomp/N64Recomp/blob/ffb39cdad1da5de07eaaa48bd1db4a89a7986771/LiveRecomp/live_recompiler_test.cpp#L301-L364) returns success after printing failures, and on missing arguments. Ghidra's [XML loader](https://github.com/NationalSecurityAgency/ghidra/blob/918d44ebc2962a53d23eeee52b8f44c7816e7815/Ghidra/Features/Decompiler/src/decompile/cpp/testfunction.cc#L262-L296) and [matcher](https://github.com/NationalSecurityAgency/ghidra/blob/918d44ebc2962a53d23eeee52b8f44c7816e7815/Ghidra/Features/Decompiler/src/decompile/cpp/testfunction.cc#L309-L350) test expected decompiler output text; this is not an original-byte matching oracle. [Empty file discovery](https://github.com/NationalSecurityAgency/ghidra/blob/918d44ebc2962a53d23eeee52b8f44c7816e7815/Ghidra/Features/Decompiler/src/decompile/cpp/test.cc#L158-L173) can produce zero failures. Limit: these are source observations, not reproduced donor failures. R6 disallows zero/all-skipped pass and requires discriminating method evidence.

7. **A failed capture must not become a golden baseline.** Ghidra MCP's [snapshot runner](https://github.com/bethington/ghidra-mcp/blob/9cc29c0f1efb6c63a7d6898c9a23aff39397f992/tests/conformance/runner.py#L251-L280) always refuses MCP-level errors during recording. It permits a body-level refusal only when the case explicitly expects that negative behavior. Its [offline regression](https://github.com/bethington/ghidra-mcp/blob/9cc29c0f1efb6c63a7d6898c9a23aff39397f992/tests/unit/test_conformance_snapshots.py#L93-L124) detects both new and stale known-bad baselines. Limit: [native Java transport parity is planned](https://github.com/bethington/ghidra-mcp/blob/9cc29c0f1efb6c63a7d6898c9a23aff39397f992/tests/conformance/README.md#L59-L75), so these bridge tests cannot prove it. Added as a checker-honesty rule for future oracle capture; no snapshot subsystem added to adopt-adapt.

8. **A source fingerprint is not a test receipt.** MCP [release evidence](https://github.com/bethington/ghidra-mcp/blob/9cc29c0f1efb6c63a7d6898c9a23aff39397f992/tools/release_evidence.py#L172-L197) writes a literal `result: passed`; [verification](https://github.com/bethington/ghidra-mcp/blob/9cc29c0f1efb6c63a7d6898c9a23aff39397f992/tools/release_evidence.py#L226-L275) binds version/path-set/source identity, not raw test output or parsed counts. Existing self-attestation guidance is reconfirmed, not novel. The same limit applies to this skill's manifest and string-valued evidence records.
