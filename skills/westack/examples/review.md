# Review and missing facilities

A generated check that always returns true passes a good fixture and incorrectly passes the broken fixture. Reject the check. A useful check distinguishes both. This is verifier validation.

A real non-author review is separate: reviewer identity/context, exact patch hash, findings, evidence, adjudication and verification. With no authorized independent reviewer, label self-review as self-review and keep required independent review not-run. Do not claim a persona is a second reviewer.

A finding that parse changed shape while CLI still expects a string needs a source location, consequence, reproduction and correction. Mark fixed only after a current integration receipt; record rejected/deferred findings with reasons and residual risks.
