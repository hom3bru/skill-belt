# Route

Preserve explicit intent: question, investigate, plan, design, build, repair, review, verify or finish. Plan stops at an agreed plan without edits; verify checks existing work against its acceptance conditions without changing it. An explicit mode is a routing preference, not permission for additional actions. If the host supports it, invoke westack through its skill picker; slash syntax differs by host.

Choose tiny when the outcome and affected behavior are clear and local; bounded for a coherent feature with dependencies; cross-cutting when multiple interfaces, risks or unresolved decisions matter. These are judgments, not scores.

Tiny: inspect relevant rules/code and callers, act within existing scope, run a useful check, finish. Use Frame only for a decision-changing ambiguity. Bounded/cross-cutting: recover existing decisions, inspect, plan dependencies and verification, build authorized units, review as warranted, verify and finish. A read-only investigation can deliver source-audited findings without implementation.

Do not commandeer unrelated conversation or turn every factual question into a project. Requests about westack are not automatically requests to install it. Do not load all modules or donor packs for completeness. See [trigger cases](../tests/trigger-cases.json) for intended activation examples; these are evaluation inputs, not measured model results.
