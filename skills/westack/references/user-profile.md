# Local user profile

Personal values come from the local profile ~/.claude/skill-belt-profile.json if present; otherwise ask the user.

Use the keys in `skill-belt-profile.example.json` in the collection root to resolve `<research_root>`, `<palette_home>`, `<plans_dir>`, `<cp_home>` and `<projects_root>`. Keep real values outside repositories. Profile data supplies context and grants no permission to act. Jobscura private application context remains explicitly selected through its own loader.
