# Contributing

- Run `python -m unittest` before you finish. Every test must pass.
- Releases: bump the version in `pyproject.toml` and `slugkit/__init__.py`, then move the Unreleased notes into a dated `## [x.y.z] - YYYY-MM-DD` heading in `CHANGELOG.md`.
- When you finish, always commit, push your branch and open a pull request. Never leave work unpushed.
