# User profile

Personal values come from the local profile ~/.claude/skill-belt-profile.json if present; otherwise ask the user.

Refer to the person as "the user" in published instructions. Use these placeholders for personal paths.

- `<research_root>` for the local research output root.
- `<palette_home>` for the local Palette library.
- `<plans_dir>` for the local plans directory.
- `<cp_home>` for the local collaboration mailbox home.
- `<projects_root>` for the local projects directory.

Resolve values from the local profile or the user when needed. Historical receipts retain their original names and paths as evidence. Hash-pinned research inputs and source URLs retain their provenance. They describe earlier work and supply no current personal defaults.
