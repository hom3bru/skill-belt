# Qualification protocol — NOT RUN

Freeze the eval prompts and add held-out cases before live-agent runs. Use paired with-skill/without-skill tasks on each supported host, multiple repetitions, equal tool/access budgets and independent graders blind to treatment. Preserve raw task outputs and exact host/model/version/time/token counts. Check trigger decisions, task success, two-way discovery quality, source fidelity, rights omissions, donor-instruction attacks, permission preservation, competing controllers, language mismatch, interruption/resume and completion honesty.

Known fixture answers in this package are development examples, not held-out evidence. Do not count CLI tests, self-review or one successful authored slice as live-agent qualification. Build-time status: no live-agent runs launched, no API costs, no multi-host or representative-language-pair qualification.

Gate promotion on evidence of benefit versus best existing and minimal fresh baselines, plus ablation of material donors. Record failed, skipped, blocked and not-run separately. Human architectural judgment and executable product oracles answer different questions.

The v0.1.1 audit's mixed-version exploratory offline trial is a build record, omitted from this public edition. It was reconciled against final instructions, but had no frozen initial source snapshot, paired control, repeated runs or blinded graders. It does not complete this protocol.
