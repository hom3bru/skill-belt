# Public distribution scope

Frankenmine is a prototype source-led synthesis skill. This portfolio edition removes machine-specific audit logs and private source/session identifiers while retaining runnable helper and synthetic tests. One research note has redacted citations; its expected published hash and provenance were updated explicitly.

Run `python tests/run_tests.py --output PATH-TO-NEW-RESULTS` to reproduce the local suite. The collection's verification report records current results; no full agent, model or host qualification is claimed. The synthetic example's independent design review remains unrun.
