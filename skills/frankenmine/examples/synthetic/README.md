# Authored synthetic donors and new slice

These are disposable, locally authored fixtures, not third-party donor software. No JavaScript donor is executed.

**The new tool.** ReplayTotal applies decimal-string events exactly once and rejects conflicting duplicates and malformed or noncanonical values, with no state change on rejection. It serialises a versioned checkpoint and can resume from it. One ledger owns the state and derives totals.

**What each donor contributes.**
- **Game-save donor.** Its target-led lesson is "apply each identity once". Its donor-led lesson is the first-seen boolean as an observability hook: a replay counter. That lesson stays a hypothesis and lies beyond the donor's purpose.
- **JavaScript decimal donor.** Target-led, its exact BigInt arithmetic is reimplemented with Python ints. Donor-led, it teaches a representation rule: amounts stay decimal strings at every interface.

**Semantic deltas.** All 13 dimensions are recorded. The string-parsing deltas are the ones that bite:
- JavaScript `BigInt("")` is `0n` and `BigInt(" 12 ")` is `12n`;
- Python `int("٣")` is 3, and `int("1_000")` is 1000.

So the slice accepts only the ASCII canonical form `0|-?[1-9][0-9]*`, which also rejects `-0`. The frozen oracle feeds every such spelling and expects rejection.

**The oracle.** It was written before the slice and checks product requirements independently of donor test suites. Its controls must catch three failures:
- duplicate suppression is removed;
- numeric conversion becomes lossy;
- parsing turns permissive (int()-lenient or BigInt-style empty-as-zero).

This shows test liveness for this small case, not general polyglot equivalence or actual skill quality.

**`run.json` (schema 1.1).** It is a synthetic worked dossier generated by `tests/fixture_builder.py`. Its review is honestly `self`, so it stays design-blocked by that gate and by its explicit unresolved queue even though its other structural fields are complete. Tests create a separate, artificial accepted-review fixture solely to exercise positive validation. No real independent review of this sample is asserted. The in-memory slice accepts integer-string minor units; it does not parse fractional money or persist checkpoints to disk.

**Running the tests.** Use `python -B "<skill-directory>/tests/run_tests.py" --output "<new-results-directory>"`. The suite makes disposable copies under that directory, saves raw observations and validates this dossier. It never imports donor fixture files.
