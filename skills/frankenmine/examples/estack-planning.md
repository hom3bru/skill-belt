# Estack — representative product synthesis

Estack is one example of the kind of product Frankenmine should help create: mechanisms from several sources must become one coherent workflow, with explicit ownership and observable behavior. It does not define Frankenmine's product domain or require other projects to use estack's modules.

A new-build prompt can request: "Use Frankenmine to design estack from the catalogue. Separate skill content, workflow control, tools, memory and host enforcement. Compare the strongest existing solution and a minimal fresh dispatcher. Inspect raw load-bearing source and rights. Preserve host permissions." For an existing prototype, use [continuation](../references/continue-synthesis.md), name the baseline and authorized output root, and state the behavior the next slice should improve.

Anticipated design questions (hypotheses, not source findings):

| Conflict to investigate | Candidate ownership decision to test |
| --- | --- |
| Repeated interviews | One brief owner; modules consume shared fields |
| Competing loops/stop conditions | One dispatcher owns transitions and termination |
| Divergent worktree rules | Host/project policy owns checkout actions |
| Approval-by-prose / permission-skipping instructions | Existing host permission system remains authoritative |
| Automatic publishing | Separate explicit user-authorized action |
| Self-attested completion | Evidence contract and independent acceptance oracle |

For each reviewed donor produce evidence → mechanism → proposed module/lesson → rights/route → seam/owner → test/falsifier. Register the full supplied manifest before selecting a bounded review subset. Defer unknowns and preserve useful lessons even when rejecting the whole tool. The version-0.1.2 continuation was exercised with an actual twenty-decision manifest: every unit was queued without importing its claims, eighteen URLs declared full commits and two stayed unpinned. Registration is not source qualification, and this example makes no catalogue-wide or runtime-effectiveness claim.
