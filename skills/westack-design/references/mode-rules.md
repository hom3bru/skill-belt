# Rules for direction, redesign and system modes

The start page keeps the other rules. Honest pages, brands and motion hold in the modes that read this page (direction, redesign, system), and motion's four defaults hold everywhere. Evidence before judgment sums up [critique](critique.md) sections 1 to 4, which critique and redesign read in full.

- **Evidence before judgment (DG-3 to DG-6).** Validate captures first, observe rather than infer, write the judgment before reading detector output, and check substance beside every ban ([critique](critique.md)).
- **Honest pages (DG-17).** No invented metric, quote, logo wall or case count; a missing fact becomes a labelled slot; a form that posts nowhere never shows success. UI copy rules: westack-docs (WD-16, `westack-docs/references/doctypes.md`).
- **Brands from sources (DG-19)**, never from memory ([direction](direction.md)).
- **Motion (DG-25).** Four defaults hold everywhere; everything else is the project's recorded policy ([motion](motion.md)).

## The helper's limits

The helper reads files, never loads or runs project code (no Tailwind config, PostCSS or plugin), writes nothing and opens no connection.

## Outside design skills

- Outside design skills (impeccable, hallmark, frontend-design, design-shotgun): only when the user names one, through the core defer map, naming its side effects and asking once per session.
