# Darker muted text (mc-pr-2b8)

The order dates and item counts were too faint. This changes `colors.muted-foreground` from #9CA3AF to #6B7280.

Contrast check: #6B7280 on the page background is 4.83:1, so the muted text now meets WCAG AA (4.5:1 for body text). Fixes the accessibility ticket about the order cards.
