# Design record

## Colour

- Text `#1f2933` on surface `#ffffff`; accent `#2563eb` for links and primary actions only.

## Type

- Inter for interface text, 14 px base, 1.5 line height. Headings use weight 600, never 700 or above.

## Spacing

- A 4 px grid. Cards use 16 px padding; sections are separated by 48 px.
