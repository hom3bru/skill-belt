tidepool 1.6 configuration

pool_mode

One of session, transaction or statement. Default: session.

Transaction mode

In transaction mode a server connection goes back to the pool after each transaction. Since 1.6, prepared statements work in transaction mode when prepared_cache is set above 0.

prepared_cache

How many prepared statements tidepool tracks per client. Default: 0 (off).

default_pool_size

Server connections per user and database pair. Default: 20.
