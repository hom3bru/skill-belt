# Fact-check fixture

Everything needed is saved here; nothing needs network access.

- `claim.md`: the claim to check, as a teammate posted it.
- `search/listing.json`: a search listing saved from a paper aggregator on 2026-10-30.
- `papers/2409.01234.txt`: the full text of the paper the listing points to.
- `index/`: lookups saved from two independent indexes (arXiv and OpenAlex), one file per lookup.
