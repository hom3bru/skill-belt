# Portfolio distribution

Skill Belt collects author-owned portable snapshots of adopt-adapt, Frankenmine and estack. The original local sources and installed skills are not edited by preparation of this repository.

| Skill | Baseline | Public distribution changes |
| --- | --- | --- |
| adopt-adapt | 3.0.0-grok-draft.r13 | General recipient routing, context-supplied profiles and path rules replace private project and machine details. The portable edition is versioned separately and retains proprietary ownership. |
| Frankenmine | 0.1.2 | Private source citations and transfer identifiers are removed; local audit logs are omitted. One research note is a redacted public copy, with its expected published hash updated explicitly. Runtime contracts and authored fixtures remain. |
| estack | 0.2.0 | Private build/session identifiers and machine-specific transcripts are omitted. Source URLs, inspection limits, contracts and runnable tests remain. |

Per-skill manifests identify the published bytes, rather than claiming equality with the private baselines. Skill snapshots preserve byte fidelity across Git checkout platforms. New validation results should be generated from the current checkout; private historical logs are not bundled as release evidence.

The helpers and synthetic fixtures were independently authored. Source references credit the research lineage and do not imply that third-party implementations are bundled, endorsed or comprehensively qualified. See the skills' research/provenance notes and the root [ownership notice](../NOTICE.md).

Full agent effectiveness, repeated comparative model trials, native host behavior and hostile-filesystem security remain outside the scope of a passing collection check.
