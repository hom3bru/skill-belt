# Skill Belt

This repository collects five independently usable toolkits under `skills/`. Keep changes scoped to the relevant skill and preserve its declared authority, evidence and qualification limits. Private project profiles, machine settings, credentials and local session logs do not belong in this public collection.

Run `python -B scripts/verify.py` before publishing changes. It uses standard-library Python checks and the five toolkit suites; westack's authored JavaScript fixture needs Node.js 24. Do not weaken checks or rewrite receipts to hide failures. Update the affected byte manifest when intentionally changing a skill snapshot.

The distribution preserves existing ownership terms. Do not add or change a license without the owner's instruction. The repository's tests do not establish model effectiveness or native host enforcement.
